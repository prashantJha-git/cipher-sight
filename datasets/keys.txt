1. Monoalphabetic Substitution Cipher

Key: plaintext ABCDEFGHIJKLMNOPQRSTUVWXYZ maps to ciphertext OFWTVHUQPCLKNYSMBJGZADEIXR.




2. Caesar Cipher

Key: Each row used its own random shift from 1 to 25




3. Vigenère Cipher (using random short key lengths between 3 and 6)

Keys: Each row has its own random key of 3 to 6 letters, spread roughly evenly: 121 rows with 3 letters, 128 with 4, 125 with 5 and 126 with 6. The keys aren’t stored in the file.




4. Hill Cipher (2x2 matrix transposition)

Keys: Each row has its own random 2x2 matrix, chosen so its determinant is coprime with 26 and the matrix can be inverted mod 26. The matrices aren’t stored in the file.
